For this assignment, I created a webpage that retrieves movie data from a JSON file using jQuery and AJAX.  I used a table because it is easy to organize and compare data such as title, genre, rating, year, and director. I also added a search bar, sorting by ratings, ratings in different colors, and an area with more details by clicking on a movie. These are some of the interactive features I added to make it user-friendly.

I also got a jQuery plugin. It is used to highlight a table row and display details of a movie by clicking on it. I also used data attributes instead of position to make it function correctly after sorting and searching. I used examples, online resources like YouTube, and some trial and error to complete this project. I also used AI to assist in debugging some errors and understanding some parts of the project I did not understand I also used it to try some more elements to enhance the website. This project taught me how data can be retrieved and displayed in a web page in an interactive way. I hope to get more creative with it as time goes on.
