I had fun learning about Three.js. It's exciting to know all the possibilities that can be done on a website with a 3D space. For this homework assignment I took what I learned in this module and also brought in one of my blender models to showcase, which I think is so nice to see something 3D you made on a webpage. The hardest part in creating a 3D scene for me turned out to be setting up cameras and lighting of the objects. At first, objects on the screen either appeared invisible or simply black as there was no light source. Thus, learning the importance of proper lighting, I realized that materials would not display correctly in case they are not exposed to any lighting source. It also took me a little to import the 3D object from blender correctly because the file was not in the proper format and there were problems with the scale. But with the help of a video I was able to find out what I was doing wrong and how to fix the problem. This was a fun assignment and I can’t wait to see what else I can do with it.
